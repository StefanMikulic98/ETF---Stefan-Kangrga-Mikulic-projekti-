# Neural Networks — Python Projects

Three neural network experiments developed in Python using Jupyter notebooks, as part of a university course on neural networks at ETF.

## Contents

| Notebook | Description |
|----------|-------------|
| `Projekat1.ipynb` | First neural network project |
| `Projekat2.ipynb` | Second neural network project |
| `Projekat3.ipynb` | Third neural network project |
| `Project_From_Neural_Nets.docx` | Written project report and analysis |
| `Neural networks_images/` | Image datasets and result visualisations |

## What is demonstrated

- Designing and training neural network architectures from the ground up
- Image classification and/or feature recognition tasks (based on the images directory)
- Data preprocessing and augmentation
- Training loop, loss tracking, and accuracy evaluation
- Visualisation of results (confusion matrices, sample predictions, training curves)

## Tech stack

- Python 3
- Jupyter Notebook
- NumPy, Pandas
- Likely: TensorFlow / Keras or scikit-learn (see individual notebooks for exact imports)

## Running

```bash
pip install jupyter numpy pandas matplotlib
# if using TensorFlow:
pip install tensorflow
jupyter notebook
```

Open the `.ipynb` files from the Jupyter interface and run cells in order.
