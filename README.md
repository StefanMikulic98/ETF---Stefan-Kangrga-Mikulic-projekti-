## Highlights

- **Web Development**: Complete React applications demonstrating state management, custom hooks, routing, Firebase backend integration, and modern CSS with Tailwind.
- **Systems Programming**: C++ and Java projects covering linked lists, tree structures, graph algorithms, multithreading, and GUI development.
- **Embedded Systems**: FreeRTOS-based real-time application on MSP430, EFM32 display drivers, HAL design, and graduate-level RTOS debugging with Percepio Tracealyzer.
- **Concurrent & Real-Time Programming**: Ada tasking, rendezvous, and protected objects used to simulate a mine safety system with periodic sensors, deadlines, and a gas/pump safety interlock.
- **Scientific Computing**: MATLAB image processing GUI with morphological operations and Gabor filtering; C++ numerical solvers using Gaussian elimination and Gauss-Seidel iteration.
- **Machine Learning**: Neural network models built and trained in Python (Jupyter notebooks); from-scratch linear regression and k-means clustering on web-scraped data.
- **Data Mining & Web Scraping**: Scrapy-based crawler feeding a MySQL warehouse, with SQL-driven cleaning, aggregation, and visualisation of book market data.
