# Java Projects

Three university assignments from the **Java Programming** course at ETF. Each covers a progressively more advanced area of Java — from basic GUI to multithreaded game development.

---

| Assignment | Topic | Key concept |
|-----------|-------|------------|
| [Domaci 1 — Ice Cream Shop](./Domaci%201/) | AWT GUI application | Layout management, event handling |
| [Domaci 2 — Phone Book](./Domaci%202/) | Contact management system | Collections, custom exceptions |
| [Domaci 3 — Mole Game](./Domaci%203/) | Interactive AWT game | Multithreading, synchronisation |

See each sub-folder for a detailed README.
